InboxBuffer catches every email your app sends — before it reaches a real person. A fake SMTP server with a clean dashboard, for developers and testers.
# Run it
$ docker run -d --name inboxbuffer -p 1081:1081 -p 1082:1082 -p 1025:1025 \
-v ./data:/data denwwer/inboxbuffer 

# Point your app at it
$ export SMTP_HOST=localhost SMTP_PORT=1025

# Watch emails arrive
$ open http://localhost:1081

design decisions

Small tool, deliberate choices. Nothing unnecessary.

No compression — on purpose

Zipping stored mail would save disk megabytes but cost RAM and CPU on your machine. Test mail is transient anyway (auto-cleanup has you covered), and a dev tool should stay light where it counts.

Cursor pagination

Keyset pagination and lean indexes keep the UI instant whether an inbox holds ten messages or a hundred thousand.

Less docs — self-explained

If a feature needs a manual, it needs a redesign. Everything is discoverable from the UI, and the API describes itself through an OpenAPI spec.

No built-in HTTPS/TLS

Put your own proxy in front (Caddy, nginx, Traefik) when you expose it beyond localhost or for testing purposes. One tool, one job.
